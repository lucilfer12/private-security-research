# Security Policy

## Scope

This repository contains security research artifacts for authorized assessments and educational reproduction.

## Reporting a repository issue

Do not submit secrets, credentials, private client information, or unreleased vulnerability details in public issues.

For client-specific matters, use the agreed private disclosure channel for that engagement.

## Research hygiene

- Use synthetic credentials and addresses in PoCs.
- Redact client-specific identifiers before publication.
- Do not target live systems from included scripts.
- Keep production secrets outside Git history.
